# TinyTang 0.1.0

The first release of TinyTang: firmware for the **Sipeed Tang Console 138K**
that runs the TinyDesk Shell and the TinyDesk desktop on the board's BL616 and
loads FPGA cores from the SD card, released with an open-flow desktop core and
the TinyNES core on a ready-to-use card.

## What is in it

- **BL616 firmware**, built on Bouffalo SDK 2.3.36.
  - TinyDesk Shell 0.1.5 as a console over the board's USB-C port, and the
    TinyDesk 0.1.5 desktop on HDMI and VGA through the desktop core.
  - Bluetooth LE keyboard and mouse (HID over GATT), paired once from the
    console and reconnected automatically from pairings kept on the card.
  - FPGA cores loaded from the card with `tangload`; PMOD sockets declared to
    each core from `/tang.ini`.
  - Firmware updates over USB with no BOOT button: `tools/tinytang_flash.py`
    from a computer, `tangflash` at the prompt, or the desktop's Software
    Update app.
  - Opening a file on the desktop runs `/root/scripts/open/<ext>.tdsh` for its
    extension; `ae350run` loads and runs a program on a core's AE350 CPU.
  - F1–F11 reach the desktop; F12 switches between the desktop and the core.
- **Desktop core** (`desktop.bin`), TinyTang's own, built entirely with the
  open flow (yosys, nextpnr-himbaechel, apicula; no Gowin EDA).  It drives HDMI
  and VGA together, holds its picture on a hot board, and rebuilds bit for bit
  from this tag.
- **TinyNES core** (`tinynes.bin`, from TinyNES `9e1c027`), also open flow:
  FCEUmm on the core's AE350, HDMI video, sound on a Pmod I2S2, Wii Classic
  Controllers, and TinyDesk available over a running game.  Double-click a
  `.nes` file on the desktop to play it.
- **Tang-Phosphor** (`phosphortang.bin`), a music player with an oscilloscope
  display, included as an example of a Gowin-built core running under this
  firmware.
- **A reproducible build.**  `deps.conf` pins every dependency by commit or
  digest, `tools/fetch-deps.sh` fetches and verifies them, and `BUILDING.md`
  gives the steps and the expected hashes.

## What you need

- A Tang Console 138K (GW5AST-138, revision C), powered from its power input,
  which is what selects TinyTang over Sipeed's debugger at power-up.
- A **2.4 GHz antenna on the dock's U.FL jack** (marked ANT, on the underside).
  The board ships without one, and bare it connects only at very short range.
- A Bluetooth LE keyboard and mouse.  Bluetooth Classic devices cannot connect.
- An SD card, and a computer for the first install and the first pairing.
- For TinyNES: Wii Classic Controllers on PMOD0, and a Pmod I2S2 on PMOD1 for
  sound.

## Installing

1. Unzip the SD card archive onto an SD card, keeping its layout, and put the
   card in the dock.  Its `README.md` describes every file.
2. **First install only:** open the case, hold the BL616's BOOT button while
   powering up, and write `bl616-firmware.bin` **at `0x40000` only**, as the
   README's quick start shows.  **Do not use `make flash`**: it writes from
   `0x0` and overwrites Sipeed's loader.  Later updates go over USB.
3. Power-cycle.  The board loads the desktop core and shows its console on the
   monitor.  `platform` at the prompt reports `dba104c-dirty.17f81b2`.
4. Connect a computer to the USB-C console port and pair the keyboard and
   mouse (`blekbd pair`, `blemouse pair`); the card's README walks through it.
   After that the computer is not needed.  Type `desktop` for TinyDesk.

## Known limitations

- The firmware identity carries `-dirty`.  The build applies two carried
  patches to TinyDesk on every configure; `BUILDING.md` names them by digest.
- Only Bluetooth LE HID devices work, and the Xbox Wireless Controller does not
  work over Bluetooth on this board: the fault is in the BL616's binary
  Bluetooth controller.  Controllers for games go on the cores' own ports.
- Rebuilding the desktop core needs a device database generated from Gowin EDA
  1.9.11.03, which cannot be redistributed; `deps.conf` pins its digest.  The
  three toolchains are pinned by digest but hosted by their publishers.
- The OLED and rotary-encoder PMODs are not fully qualified.
- nand2mario's nestang NES and menu cores are not part of this release.
- `phosphortang.bin` cannot be rebuilt without Gowin EDA.
